# What lolpdf has beyond the usual free PDF sites

Tools that are not in the standard free PDF-site lineup (checked against the ilovepdf.com home page tool list on 7 Oct 2026):

1. Remove background (runs on device, clear or colored output)
2. Compress image to an exact KB target
3. Resize image with presets (Instagram, WhatsApp profile, passport, Full HD)
4. Convert image JPG / PNG / WebP
5. Passport and ID photo maker with a print-ready 4x6 in or A4 sheet (India 35x45 mm, US 2x2 in, more)
6. Remove photo location and camera data (EXIF/GPS)
7. QR code maker: link, WiFi, UPI payment (PNG and SVG)
8. PDF metadata cleaner, with a list of the hidden details found
9. Scan to PDF with document clean-up (black & white, grayscale, color boost)

Features inside tools:

10. Compress PDF to an exact target size (100 KB, 200 KB, 500 KB, 1 MB or custom)
11. Watermark in any language, including Hindi
12. Delete / extract pages by ranges with words like last, odd, even
13. Drag-and-drop page organizer with thumbnails
14. Batch mode: many files at once, one ZIP back
15. Before and after size comparison
16. Clean file names (WhatsApp and government portals reject spaces and symbols)
17. Ctrl K search, keyboard shortcuts, paste images from clipboard
18. Works offline after the first visit
19. Recent activity kept only on the device (names and sizes, never contents)
20. Cursor follower that reacts to buttons, drop areas and fields
